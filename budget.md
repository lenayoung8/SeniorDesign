## Budget

Our project is focused on developing a software-based IoT security web interface, so direct expenses are minimal. The main “cost” of the project comes from the engineering time invested by the team.

### Estimated Project Budget

| Category            | Description                                              | Estimated Cost |
|---------------------|----------------------------------------------------------|----------------|
| **Software / Tools** | Open-source tools (Python, Nmap, FastAPI, React)        | **$0**         |
| **Cloud / Hosting (optional)** | Temporary hosting for dashboard/API testing | $10–$20        |
| **Miscellaneous**   | Printing, demo materials, small testing expenses         | $20            |
| **Human Resources** | 5 members × 40 hours × $26/hour                          | **$5,200**     |
| **Total Estimated Cost** |                                                      | **≈ $5,240**   |

### Notes
- No hardware purchases are required because the system runs on existing laptops.  
- Estimated hours will be tracked as the project progresses.  
- Labor cost represents the value of engineering work, not money spent by the team.
- Current rate is set at $26 an hour for 40 hours of work per team member, but is subject to change.
